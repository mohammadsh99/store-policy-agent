# Store Policy Agent

A standalone Python demo that retrieves relevant passages from a sample store policy with Sentence Transformers and FAISS, then uses an Ollama model to answer policy questions. The agent's tool response includes passage IDs intended to support the final answer.

## Project structure

```text
store-policy-agent/
├── build_index.py
├── store-policy.txt
├── policy_search.py
├── store_agent.py
├── requirements.txt
├── .gitignore
├── README.md
└── examples/
    ├── parallel_demo.py
    └── sub_agents.py
```

`build_index.py` creates the vector index and passage records from `store-policy.txt`. `policy_search.py` searches those files, and `store_agent.py` connects the search tool to Ollama. The scripts in `examples/` are standalone demos of parallel work and separate return/shipping agents; they do not depend on the FAISS index.

## Setup

Install Python 3 and Ollama. From this project folder, install the Python dependencies and download the model used by the agent and sub-agent demo:

```powershell
python -m pip install -r requirements.txt
ollama pull llama3.1:8b
```

Make sure the Ollama service is running before running `store_agent.py` or `examples/sub_agents.py`.

## Build and run

Build the index after creating or changing the policy:

```powershell
python build_index.py
```

The script prints the number of vectors saved and creates `store.faiss` and `chunks.json` in this folder. Then run the retrieval check and agent:

```powershell
python policy_search.py
python store_agent.py
```

Run either standalone example from the project folder:

```powershell
python examples\parallel_demo.py
python examples\sub_agents.py
```

[2] We deliver to Sakhnin. The delivery fee is 20 NIS.

The agent answered both parts of its sample question:

```text
Final answer: Based on the store policy, you can return the product since it has been 10 days since delivery, which is within the 14-day return window.

The delivery fee to Sakhnin is 20 NIS.
```

In the verification run above, the final answer did not include passage IDs, even though the tool retrieved passages `[1]` and `[2]`. The response is generated by the local model and may vary; that run did not satisfy the requested citation check.

## Generated files

`store.faiss` and `chunks.json` are generated locally by `build_index.py`. Both are listed in `.gitignore`, so they are excluded from Git. Each copy of this project builds its own index files.
